    数据类型

    数据类型¶

    Tips

    在 Python 中，变量没有类型，所说的"类型"是变量所指的内存中对象的类型

    分类：

    • 不可变数据：Number（数字）、String（字符串）、Tuple（元组）
    • 可变数据：List（列表）、Dictionary（字典）、Set（集合）

    数字¶

    1. python3支持的数字类型：int、float、bool、complex（复数）

    Notice!

    1. python3中的int表示长整型，没有long int
    2. 查询变量所指的对象类型的方法
    • type(x)：输出对应的数据类型
    • isinstance(x,int)：如果x的数据类型为int，则输出True；反之输出False
    del语句
    Python
    1
2
3
4
5
6
7
8
    del x               # 删除单个变量
del a, b, c         # 删除多个变量

# 删除容器中的元素
lst = [10, 20, 30]
del lst[1]          # 删除索引1的元素：lst变为[10, 30]
d = {"key1": 1, "key2": 2}
del d["key1"]       # 删除键"key1"：d变为{"key2": 2}

    字符串¶

    常见操作¶

    1. 加法
    Python
    1
2
3
    s1 = "Hello"
s2 = "World"
print(s1 + s2)      # Output: HelloWorld
    1. 乘法
    Python
    1
2
    s = "abc"
print(s * 3)        # Output: abcabcabc

    Tips

    乘的数字一定是整型，浮点数会报错！！！

    1. 分割

    s.split()将字符串s按照空格（包括多个空格，制表符\t，换行符\n等）进行分割，返回一个列表[s1, s2, ...]

    Python
    1
2
3
    s = "Hello World\tlucy\nwisteria"
lst = s.split()
print(lst)          # Output: ['Hello', 'World', 'lucy', 'wisteria']
    1. 连接

    与分割相反，s.join(lst)将列表lst中的元素用s作为连接符连接，返回一个字符串

    Python
    1
2
3
    lst = ["Hello", "World", "lucy", "wisteria"]
s = "-"
print(s.join(lst))   # Output: Hello-World-lucy-wisteria
    1. 替换

    s.replace(old, new)将字符串s中的old替换为new，返回一个新的字符串

    Python
    1
2
    s = "Hello World World"
print(s.replace("World", "lucy"))   # Output: Hello lucy lucy
    1. 大小写转换

    （1） s.upper()：将字符串s中的所有字符转换成大写 （2） s.lower()：将字符串s中的所有字符转换成小写

    Python
    1
2
3
4
    s = "Hello World"
print(s.upper())    # Output: HELLO WORLD
print(s)            # Output: Hello World
print(s.lower())    # Output: hello world

    Tips

    字符串的大小写转换不会改变原字符串，而是返回一个新的字符串！！！

    1. 求长度：len(s)

    索引与分片¶

    1. 索引 s = "Hello World"
    • 正向索引：s[0] = 'H'
    • 负索引值：s[-1] = 'o'
    1. 分片

    s[start:end:step]：范围为[start, end)，步长为step（默认为1），返回一个新的字符串

    Python
    1
2
3
4
    s = "Hello World"
print(s[::-1])      # Output: dlroW olleH
print(s[::2])       # Output: HloWrd
print(s[0:-1:2])    # Output: HloWr

    元组¶

    1. 创建：元组Tuple是个有序序列，但是元组是不可变的（不可修改！！！），用()或tuple()生成

    Notice!

    创建单个元素的元组时，必须在元素后面添加逗号，否则括号会被当作数学运算中的括号！

    Python
    1
2
3
4
    t1 = (1,)          # 创建单个元素的元组
t2 = (1)           
print(type(t1))    # Output: <class 'tuple'>
print(type(t2))    # Output: <class 'int'>
    1. 元组与列表相互转换：list(t)和tuple(lst)

    Python
    1
2
3
    a = (10, 11, 12, 13, 14)
b = list(a)
print(type(b))   # Output: <class 'list'>

    列表¶

    Tips

    1. 列表中的元素可以是不同的数据类型
    2. 空列表：[]或list()

    常见操作¶

    1. 求长度：len(lst)
    2. 加法：相当于将两个列表按顺序连接
    Python
    1
2
3
4
    lst1 = [1, 2, 3]
lst2 = [4, 5, 6]
lst3 = lst1 + lst2
print(lst3)          # Output: [1, 2, 3, 4, 5, 6]

    1. 乘法：相当于将列表重复相加

    2. 索引与分片：同字符串

    添加元素¶

    1. 添加单个元素 append(x)

    lst.append(x)：在列表lst的末尾添加元素x

    Python
    1
2
3
    lst = [1, 2, 3]
lst.append(4)
print(lst)          # Output: [1, 2, 3, 4]

    Tips

    注意：

    append(x)每次只添加一个元素，并不会因为这个元素是序列而将其展开！

    Python
    1
2
3
    lst = [1, 2, 3]
lst.append([4, 5, 6])
print(lst)          # Output: [1, 2, 3, [4, 5, 6]]
    1. 添加序列元素 extend(lst)

    lst1.extend(lst2)：在列表lst1的末尾依次添加序列lst2中的所有元素（相当于加法）

    Python
    1
2
3
4
    lst1 = [1, 2, 3]
lst2 = [4, 5, 6]
lst1.extend(lst2)
print(lst1)          # Output: [1, 2, 3, 4, 5, 6]
    1. 插入元素 insert(index, x)

    lst.insert(index, x)：在列表lst的索引为index的位置插入元素x，之后的元素都向后移动一位

    Python
    1
2
3
    lst = [1, 2, 3]
lst.insert(1, 4)
print(lst)          # Output: [1, 4, 2, 3]

    删除元素¶

    1. del lst[index]：根据下标进行删除
    Python
    1
2
3
    lst = [1, 2, 3, 4, 5]
del lst[2]
print(lst)          # Output: [1, 2, 4, 5]
    1. lst.pop(index)：弹出元素
    • 如果不指定index，则默认弹出最后一个元素
    • 如果指定index，则删除指定位置的元素，并返回该元素的值
    Python
    1
2
3
4
5
    lst = [1, 2, 3, 4, 5]
lst.pop()
print(lst)          # Output: [1, 2, 3, 4]
print(lst.pop(2))   # Output: 3
print(lst)          # Output: [1, 2, 4]
    1. lst.remove(x)：根据元素的值进行删除
    • 如果列表中存在多个元素，则删除第一个出现的元素
    • 如果元素不存在，则会报错
    Python
    1
2
3
4
    lst = [1, 2, 3, 4, 3]
lst.remove(3)
print(lst)          # Output: [1, 2, 4, 3]
lst.remove(5)       # Output: ValueError: list.remove(x): x not in list

    测试从属关系¶

    1. in：判断元素是否在某个序列（不只是列表）中
    2. not in：判断元素是否不在某个序列中
    Python
    1
2
3
    lst = [1, 2, 3, 4, 5]
print(3 in lst)     # Output: True
print(3 not in lst) # Output: False
    1. lst.index(x)：返回元素x的第一个出现的索引；如果元素不存在，则会报错
    Python
    1
2
    lst = [1, 2, 3, 4, 3]
print(lst.index(3))  # Output: 2
    1. lst.count(x)：返回元素x在列表中出现的次数
    Python
    1
2
    lst = [1, 2, 3, 4, 3]
print(lst.count(3))  # Output: 2

    修改元素¶

    lst[index] = x：根据下标进行修改

    Python
    1
2
3
    lst = [1, 2, 3, 4, 5]
lst[2] = 6
print(lst)          # Output: [1, 2, 6, 4, 5]

    排序¶

    1. lst.sort(lst)：对列表进行排序
    • 默认情况下，从小到大排序
    • 如果指定reverse=True，则从大到小排序
    Python
    1
2
3
4
5
    lst = [5, 2, 4, 6, 1]
lst.sort()
print(lst)          # Output: [1, 2, 4, 5, 6]
lst.sort(reverse=True)
print(lst)          # Output: [6, 5, 4, 2, 1]
    1. sorted(lst)：返回一个新的列表，该列表是原列表的排序版本；原列表不变
    Python
    1
2
3
4
    lst = [5, 2, 4, 6, 1]
new_lst = sorted(lst)   # 反向：new_lst = sorted(lst, reverse=True)
print(new_lst)      # Output: [1, 2, 4, 5, 6]
print(lst)          # Output: [5, 2, 4, 6, 1]
    1. lst.reverse()：将列表逆序
    Python
    1
2
3
    lst = [1, 2, 3, 4, 5]
lst.reverse()
print(lst)          # Output: [5, 4, 3, 2, 1]

    Note

    如果不想改变原列表，可以使用分片lst[::-1]

    Python
    1
2
3
4
    lst = [1, 2, 3, 4, 5]
new_lst = sorted(lst[::-1])  
print(new_lst)      # Output: [5, 4, 3, 2, 1]
print(lst)          # Output: [1, 2, 3, 4, 5]

    字典¶

    1. 空字典创建：{}或dict()

    2. 插入键值/更新键值：dic[key] = value

    Tips

    1. 字典的键必须是数字、字符串、元组等不可变数据，不能是列表、字典、集合

    2. 字典没有顺序：当我们 print 一个字典时，并不一定按照插入键值的先后顺序进行显示，因为字典中的键本身不一定是有序的

    1. 查看键值
    • dic[key]：根据键key获取对应的值
      • 但是当键不存在时，会报错
    • dic.get(key, default=None)：当键不存在时，返回default值（默认为None）
    Python
    1
2
3
    dic = {"name": "lucy", "age": 20, "gender": "female"}
print(dic["name"])                    # Output: lucy
print(dic.get("city", "not found"))   # Output: not found

    1. 删除键值对：del dic[key]

    2. 查看字典中各种数据

    • d.keys() ：返回一个由所有键组成的列表
    • d.values() ：返回一个由所有值组成的列表
    • d.items() ：返回一个由所有键值对元组组成的列表
    Python
    1
2
3
4
    d = {"name": "lucy", "age": 20, "gender": "female"}
print(d.keys())   # Output: dict_keys(['name', 'age', 'gender'])
print(d.values()) # Output: dict_values(['lucy', 20, 'female'])
print(d.items())  # Output: dict_items([('name', 'lucy'), ('age', 20), ('gender', 'female')])

    集合¶

    Note

    1. 集合set是无序且不重复的元素序列
    2. 集合set的元素必须是不可变数据，不能是列表、字典、集合
    1. 创建：set()或{}或使用列表来初始化一个集合
    Python
    1
2
3
4
    s1 = set()
s2 = {1, 2, 3, 4, 5}
s3 = set([1, 2, 3, 4, 1])   # 集合会自动去除重复元素
print(s3)          # Output: {1, 2, 3, 4}

    Tips

    但是创建空集合的时候只能用set来创建，因为在 Python 中{}创建的是一个空的字典

    Python
    1
2
    s = {}
print(type(s))      # Output: <class 'dict'>
