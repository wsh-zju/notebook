    运算符重载¶

    1. 运算符重载：允许用户自定义类型像内置类型一样使用运算符（调用函数的另一种方式）

    可以被重载的运算符

    1. 算术与位运算符：+ - * / % ^ & | ~
    2. 赋值运算符：= += -= *= /= %= ^= &= |=
    3. 移位运算符：<< >> >>= <<=
    4. 关系运算符：== != < > <= >=
    5. 逻辑运算符：! && ||
    6. , -> ->() [] new delete new[] delete[] ++ --

    不能重载的运算符

    1. .()：成员访问运算符
    2. .*：成员指针访问运算符
    3. ::：作用域解析运算符
    4. ?:：三目运算符
    5. sizeof
    6. typeid：类型识别运算符
    7. static_cast dynamic_cast const_cast reinterpret_cast：强制类型转换运算符
    1. 限制
    • 只有现有的运算符可以被重载 e.g. 不能为幂运算创建 ** 运算符
    • 运算符必须在类或枚举类型上进行重载
    • 重载的运算符必须保持操作数的数量，保持优先级

    实现类型¶

    1. 成员 vs 全局函数
    • 一元运算符应当作为成员函数
    • = [] ->() ->* 必须作为成员函数
    • 所有其他二元运算符作为非成员函数
    1. 参数传递
    • 将只读参数作为 const 引用传入（内置类型除外）
    • 将不改变类的成员函数设为 const（布尔运算符、+、- 等）
    • 全局函数：如果左侧操作数发生变化，则以引用方式传递（赋值运算符）
    1. 返回值：根据运算符预期的含义选择返回类型
    C++
    1
2
3
    const T operatorX(const T& l, const T& r);  //  + - * / % ^ & | ~
bool operatorX(const T& l, const T& r);     //  ! && || < <= == != > >=
E& T::operator[](int index);                // []

    Warning

    返回一个新对象时，将其作为 const 对象返回

    防止结果作为左值被修改 e.g. (a + b) = c

    输入/输出运算符¶

    1. 必须是全局函数，一般设置为友元（可以每一个类对应一对输入输出）
    2. 参数：必须是两个参数
    • 第一个参数：istream& or ostream&
    • 第二个参数：一个值的引用
      • 输出：使用 const T&（只读取不修改）
      • 输入：使用 T&（需修改）
    1. 返回值：istream& or ostream&（支持链式操作）
    C++
    1
2
    cin >> a >> b >> c;
cout << a << b << c;

    链式操作

    1. 先运算 cin >> a
    2. 运算结束之后返回 cin
    3. 整个表达式相当于 cin >> b >> c，以此类推

    赋值运算符¶

    1. 必须是成员函数

    Tip

    如果不希望类的对象被赋值，则将赋值运算符显式声明为 private 成员函数

    1. 如果没有提供将自动生成
    • 行为与自动生成的拷贝构造函数相同
    • 如果有指针，则必须手动提供赋值运算符重载
    Text Only
    1
    A = B = C;  // 执行过程为 A = (B = C);
    1. 返回值：*this 的引用
    2. 实现：需要检查是否是自我赋值（通过检查地址）
    C++
    1
2
3
4
5
6
7
    T& T::operator=( const T& rhs ) {
    // 检查自我赋值
    if ( this != &rhs ) {
        // 执行赋值
    }
    return *this;
}

    为什么要检查自我赋值？

    1. 因为赋值给的是一个已经存在的对象，该对象必须先 delete 掉，再 new 一个新的对象，之后才能拷贝内容
    2. 如果不检查，就会同时把两个对象都 delete 掉，从而导致程序崩溃

    值类

    1. 表现得像原始数据类型
    2. 具有重载运算符（通常）
    3. 可以与其他类型相互转换
    4. 示例：Complex（复数）、Date（日期）、String（字符串）

    1. 将别的类型转换为本类型：使用一个参数的构造函数

    1. 将本类型转换为另一个类型：X::operator T ()
    • 运算符名称可以是任何类型描述符
    • 没有显式参数
    • 没有返回类型声明，返回类型与函数名称 T 相同
    • 编译器将其用作从 X 到 T 的类型转换
    • 函数会被自动调用

    1. 隐式转换（针对任何类型 T）：T -> T& t& -> T T* -> void* T[] -> T* T* -> T[] T -> const T

    2. 使用显式转换函数：在类中，声明一个成员函数来代替转换运算符
