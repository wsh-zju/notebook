    马克思主义基本原理¶

    Tips

    整理比较重要的知识点，适合考前抱佛脚嘻嘻

    论述题考点：辩证唯物，历史唯物，政治经济学

    资料

    1. 马克思主义的直接理论来源：德国古典哲学、英国古典政治经济学、英法空想社会主义
    2. 马克思主义产生的自然科学前提：19 世纪三大科学发现，细胞学说、能量守恒与转化定律、生物进化论
    3. 马克思主义首要和基本的观点：实践性
    4. 马克思主义的基本特质：科学性与革命性的同一

    辩证唯物主义¶

    • 古代朴素唯物主义：用一种或几种物质作为本原来解释世界

    • 近代形而上学唯物主义：把物质等同于物质的微观结构层次——原子

    1. 实践是正确发挥人的主观能动性的根本途径
    2. 发展的实质是新事物的产生、旧事物的灭亡
    3. 规律的根本特点：客观性
    4. 具体问题具体分析是马克思主义活的灵魂。
    5. 辩证的逻辑思维方法：1.归纳与演绎 2.分析与综合 3.抽象与具体 4.逻辑与历史
    6. 系统的基本特质：1.整体性 2.结构性 3.层次性 4.开放性

    马克思主义物质观¶

    1. 思维和存在的关系（或称物质和意识的关系）问题是哲学的基本问题

      • 何者为第一性：唯物主义和唯心主义
      • 是否具有同一性：可知论和不可知论

    2. 物质与意识

      • 物质决定意识，意识对物质有反作用（能动作用）
      • 物质的根本属性是运动，运动是绝对的，静止是相对的
      • 既要尊重客观规律（前提），也要发挥主观能动性（条件）

    3. 世界的物质统一性原理是辩证唯物主义最基本、最核心的观点，是马克思主义的基石（体现在自然界是物质的，具有客观实在性，人类社会也是物质的，意识统一于物质）

    唯物辩证法¶

    1. 唯物辩证法认为：世界上的万事万物都处于普遍联系之中，普遍联系引起事物的变化发展
    2. 联系和发展的观点是唯物辩证法的总观点、总特征
    3. 联系的特点：1.客观性 2.普遍性 3.多样性 4.条件性
    4. 事物变化发展的一般规律：对立统一规律 、量变质变规律、否定之否定规律（揭示事物发展的趋势和道路）

    5. 对立统一规律是唯物辩证法的实质和核心

      • 揭示事物运动变化的基本动力
      • 对立/统一是矛盾的两个属性（斗争性/同一性）
      • 矛盾具有普遍性和特殊性

    6. 量变质变规律：模式：量变 → 质变 → 新的量变

      • 量变体现连续性，质变体现中断
      • 量变是质变的必要准备，质变是量变的必然结果，质变后是新的量变
    7. 否定之否定规律：揭示事物发展的趋势和道路（肯定——否定——否定之否定）

    实践与认识¶

    实践¶

    1. 实践的观点是马克思主义的基本观点。
    2. 实践是人类生存和发展最基本的活动，是人类社会生活的本质，是人的认识产生和发展的基础，也是真理与价值统一的基础
    3. 实践是确定性与不确定性的统一
    4. 实践的三个基本特征：客观实在性、自觉能动性、社会历史性
    5. 实践的本质是人类能动地改造世界的社会性的物质活动
    6. 实践的基本形式：物质生产实践（最基本）、社会政治实践 、科学文化实践

    7. 实践的主体、客体和中介是实践活动的三项基本要素

      • 主体是人；客体是和实践主体互动的客观存在事物；中介包含身体的延展和语言
      • 主客体相互作用的关系：实践关系（最根本） 、认识关系、价值关系
      • 主体客体化是主体改造客体，客体主体化就是客体影响主体

    8. 实践和认识的关系：实践是认识的基础

      • 实践是认识的来源（做了就知道了）
      • 实践是认识发展的动力（做了之后会想更多）
      • 实践是认识的目的（学知识是为了将来能用上）
      • 实践是检验认识真理性的唯一标准

    认识¶

    1. 认识的本质：主体在实践基础上对客体的能动反映

    2. 认识过程的两次飞跃：

      • 从实践到认识：在实践基础上认识活动由感性认识能动地飞跃到理性认识

        • 感性认识的基本方式：感觉、知觉、表象
        • 理性认识的基本方式：概念、判断、推理

      • 再从认识到实践（理论付诸实践）

    3. 认识过程是经过多次反复的（螺旋上升）

    真理与价值¶

    1. 真理

      • 真理是客观的
      • 真理具有绝对性和相对性
      • 客观性是真理的本质属性，但是真理的形式又是主观的
      • 真理和谬误作为矛盾对立统一，可以相互转化

    2. 价值

      • 价值是客体对主体所具有的意义
      • 价值的基本特性：1.主体性 2.客观性 3.多维性 4.社会历史性

    3. 认识世界和改造世界要：一切从实际出发（认识路线）、实事求是（思想路线）、解放思想（思想和实际相符）、守正创新

    历史唯物主义¶

    历史唯物主义又称唯物史观

    社会存在与社会意识¶

    1. 社会存在与社会意识的关系问题，是社会历史观的基本问题

      • 唯心史观：社会意识决定社会存在
      • 唯物史观：社会存在决定社会意识

    2. 社会存在决定社会意识，社会意识是社会存在的反映，并反作用于社会存在

    3. 社会意识具有相对独立性

      • 社会意识与社会存在发展不完全同步，有进步和落后之分
      • 社会意识相互影响，有历史继承性
      • 社会意识对社会存在有能动的反作用（社会意识相对独立性突出表现）

    社会基本矛盾¶

    1. 社会基本矛盾是历史发展的根本动力，推动社会形态由低级向高级演进
    2. 社会基本矛盾，贯穿并制约着社会发展的全过程，规定社会发展过程的基本性质
    3. 生产力与生产关系、经济基础与上层建筑之间的矛盾，是人类社会基本矛盾
    4. 阶级和阶级斗争观点是唯物史观的基本观点；阶级斗争是社会发展的直接动力

    生产力与生产关系¶

    1. 物质生产方式是社会存在和发展的基础及决定力量

    2. 生产方式=生产力＋生产关系，生产力是生产的物质形式，生产关系是生产的社会形式

    3. 生产力是人类在生产实践中形成的改造和影响自然以使其适合社会需要的物质力量

      • 基本要素：劳动资料（劳动资料最重要的是生产工具）、劳动对象、劳动者（主导作用/最活跃）
      • 生产工具是区分社会经济时代的客观根据，是衡量生产力发展水平的客观标准
      • 科学技术是先进生产力的集中体现和主要标志，是第一生产力

    4. 生产关系是社会关系中最基本的关系

      • 人在生产过程中形成的不以人的意志为转移的经济关系
      • 包括生产资料所有制关系（最基本，人们进行物质资料生产的前提）、生产中人与人的关系、产品分配关系

    5. 生产力决定生产关系，而生产关系又反作用于生产力（社会发展的最根本矛盾）

    经济基础与上层建筑¶

    1. 政治上层建筑居于上层建筑的主导地位，国家政权是政治上层建筑的核心
    2. 经济基础决定上层建筑，上层建筑反作用于经济基础
    1. 社会基本矛盾规定了社会基本结构

    2. 社会基本结构主要包括经济结构（广义）、政治结构和观念结构

      • 广义的经济结构指生产方式，包括生产力和生产关系
      • 狭义指经济关系或经济制度

    3. 社会基本矛盾在历史发展中的作用：

      • 生产力是社会基本矛盾运动中最基本的动力因素，是人类社会发展和进步的最终决定力量
      • 生产力是社会进步的根本内容，是衡量社会进步的根本尺度
      • 社会基本矛盾特别是生产力和生产关系的矛盾，决定着社会中其他矛盾的存在和发展
      • 经济基础和上层建筑的矛盾也会影响和制约生产力和生产关系的矛盾
      • 社会基本矛盾具有不同的表现形式和解决方式，并从根本上影响和促进社会形态的变化和发展

    4. 社会主要矛盾是社会基本矛盾的具体体现

    人民群众与历史¶

    唯心史观：英雄史观；唯物史观：群众史观

    1. 人民群众是社会历史的主体，是历史的创造者
    2. 人民群众是社会物质财富的创造者，社会精神财富的创造者，社会变革的决定力量
    3. 一定历史阶段所达到的生产力水平是人民群众创造历史的物质基础和前提
    4. 群众路线是我们党的生命线和根本工作路线；群众观点是无产阶级政党的根本观点

    政治经济学¶

    劳动价值论¶

    1. 商品经济是以交换为目的而进行生产的经济形式。
    2. 商品具有使用价值和价值两个因素/属性，是使用价值和价值的矛盾统一体。
      • 使用价值是商品的自然属性， 是一切劳动产品所共有的属性
      • 决定商品交换的比例的不是商品的使用价值，而是价值
      • 价值是一种社会关系，价值是商品所特有的社会属性
      • 价值是交换价值的基础，交换价值是价值的表现形式
    3. 劳动具有二重性，即具体劳动（具体工序）和抽象劳动（无差别劳动）
      • 具体劳动创造使用价值，抽象劳动创造价值
    4. 商品价值量
      • 决定因素：社会必要劳动时间（以简单劳动为尺度）
      • 与生产商品所耗费的社会必要劳动时间成正比，与劳动生产率成反比
    5. 货币是在长期交换过程中形成的固定充当一般等价物的商品， 是商品经济内在矛盾发展的产物。货币最基本的职能是价值尺度和流通手段。
    6. 价值规律：商品的价值量由生产商品的社会必要劳动时间决定，商品交换以价值量为基础，按照等价交换的原则进行。商品的价格围绕商品的价值按照供求关系波动。
    7. 价值规律的利弊：
      • 自发地调节生产资料和劳动力在社会各生产部门之间的分配比例；自发地刺激社会生产力的发展；自发地调节社会收入的分配
      • 导致社会资源浪费；阻碍技术进步；导致收入两极分化
    8. 商品的使用价值和价值的矛盾、 生产商品的具体劳动和抽象劳动的矛盾根源于私人劳动和社会劳动的矛盾
    9. 商品经济以私有制为基础，私人劳动和社会劳动的矛盾是商品经济的基本矛盾。

    剩余价值论¶

    • W—G—W，简单商品流通公式
    • G—W—G'，资本流通公式
    1. 劳动力成为商品是资本增值的原因
    2. 劳动力成为商品的条件：劳动者在法律上是自由人；劳动者没有任何生产资料，不得不依靠出卖劳动力为生
    3. 劳动力的价值：维持劳动者本人生存所必需的生活资料的价值、维持劳动者家属的生存所必需的生活资料的价值、劳动者接受教育和训练所支出的费用。

    1. 剩余价值理论是马克思经济学说的核心内容和基石。

    2. 剩余价值规律：资本主义生产的直接目的和决定性动机，就是无休止地获取尽可能多的剩余价值

    3. 剩余价值是由雇佣工人的剩余劳动创造的

    4. 资本主义生产过程具有二重性，一方面是生产物质资料的劳动过程；另一方面是生产剩余价值的过程，即价值增殖过程。

      • 资本主义生产过程是劳动过程和价值增殖过程的统一。
      • 劳动过程包括三个基本要素，即劳动者的劳动、劳动对象和劳动资料。
      • 价值增殖过程中雇佣工人的劳动分为两部分：一部分是必要劳动，用于再生产劳动力的价值；另一部分是剩余劳动，用于无偿地为资本家生产剩余价值。

    5. 在剩余价值生产中有不变资本和可变资本两类资本

      • 不变资本（c）是以生产资料形态存在的资本。生产资料的价值通过工人的具体劳动被转移到新产品中，其转移的价值量不会大于它原有的价值量
      • 可变资本（v）是用来购买劳动力的那部分资本。由工人的劳动再生产出来。在生产过程中，工人所创造的新价值不仅包括相当于劳动力价值的价值，而且还包括一定量的剩余价值

    6. W(商品价值)=c(不变资本)+v(可变资本)+m(剩余价值)

    7. 剩余价值率m'=m（剩余价值或称利润）/v（可变资本或称工资）=剩余劳动时间/必要劳动时间

    8. 剩余价值生产方法：绝对剩余价值的生产和相对剩余价值的生产

      • 绝对剩余价值的生产通过延长工作时长和提高劳动强度实现（加班）
      • 相对剩余价值的生产通过改善技术和管理且不改变工资工时来实现

    9. 资本主义的根本目的是追求剩余价值

    10. 剩余价值的资本化，就是资本积累

      • 资本积累不但是社会财富占有两极分化的重要原因
      • 而且是资本主义社会失业现象产生的根源

    11. 在资本主义制度下，工人的工资是劳动力价值，这是资本主义工资的本质。

    12. 生产社会化和生产资料资本主义私人占有之间的矛盾，是资本主义的基本矛盾
    13. 生产相对过剩是资本主义经济危机的本质特征（实质），即相对于劳动人民有支付能力的需求来说社会生产的商品显得过剩
    14. 经济危机的表现：生产过剩、失业增加、企业破产

    资本主义上层建筑¶

    包括资本主义的政治上层建筑和观念上层建筑，前者集中体现为资本主义政治制度，后者主要体现为资本主义意识形态。

    1. 资本主义国家的职能以服务于资本主义制度和资产阶级利益为根本内容
      • 对内实行政治统治和社会管理
      • 对外进行国际交往和维护国家安全及利益
    2. 资本主义国家的政治统治是通过资本主义民主制度实现
    3. 资本主义法律制度是资本主义民主制度的重要内容
    4. 宪法是资本主义国家法律制度的核心
    5. 资本主义意识形态一以贯之的核心思想主要是私有制神圣不可侵犯观念和个人主义价值观
    6. 资本主义意识形态的本质是为资本主义国家的政治上层建筑服务的，是资产阶级的阶级意识的集中体现。

    垄断资本主义¶

    资本主义的发展经历了两个阶段：自由竞争资本主义和垄断资本主义。19世纪70年代到20世纪初是过渡阶段。

    1. 形成原因：自由竞争引起生产集中和资本集中，生产集中和资本集中发展到一定阶段必然引起垄断，这是资本主义发展的客观规律
    2. 垄断的本质：获取高额垄断利润
    3. 金融资本是由工业垄断资本和银行垄断资本融合在一起而形成的一种垄断资本。
    4. 金融寡头是指操纵国民经济命脉，并在实际上控制国家政权的少数垄断资本家或垄断资本家集团
    5. 国家垄断资本主义
      • 定义：是国家政权和私人垄断资本融合在一起的垄断资本主义
      • 是生产社会化程度进一步提高之后需要国家调整帮助私人垄断的结果
      • 形式：国家所有并直接经营企业，国家与私人共有、合营企业，国家通过多种形式参与私人垄断资本的再生产过程，宏观调节，微观规制。
      • 作用：有提高生产力的积极作用，但没有改变垄断资本主义的性质，仍然加大了剥削，维护统治
    6. 帝国主义 = 垄断资本主义发展到最高阶段
    7. 经济全球化
      • 表现：生产全球化、贸易全球化、金融全球化
      • 原因：科学技术的进步和生产力的发展（根本）、跨国公司的发展提供了适合的组织形式、各国经济体制的变革
      • 好处：提高资源配置效率，促进生产力发展，给发展中国家带来先进技术、就业机会、国际贸易等
      • 坏处：加大发达国家和发展中国家的不平等，加剧发展中国家资源短缺和环境污染、增加经济风险

    当代资本主义¶

    1. 变化：
      • 生产资料所有制的变化：私人资本所有制-私人股份资本所有制-国家资本所有制发挥重要作用，法人资本所有制主导
      • 垄断资本形式的变化
      • 劳资关系和分配关系的变化：控制更加严格，剥削方式更隐蔽，出现了激励制度和福利制度缓和矛盾
      • 社会阶层和阶级结构的变化：企业所有权（资本家）和控制权（高级经理）分离、知识型服务型劳动者增加
      • 经济调节机制和经济危机形态的变化：国家干预-强化市场弱化政府
      • 政治制度的变化：政治制度多元化，公民权利扩大，改良政党力量扩大
    2. 变化的原因：科技和生产力发展（根本），工人阶级斗争，社会主义优越性的影响，改良主义政党的改革
    3. 资本主义的本质没有改变，资本主义生产关系的根本性质没有改变
    4. 大变局中的问题：经济发展失调、政治体制失灵、社会融合机制失效

    资本主义的历史地位和发展趋势¶

    1. 资本主义的进步性：

      • 将科学技术转变为强大生产力，推动了社会生产力的迅速发展，促进了社会和科技进步
      • 打破了封建制度

    2. 资本主义的局限性：

      • 资本主义的基本矛盾阻碍社会生产力的发展
      • 资本主义制度下财富占有两极分化，引发经济危机
      • 资产阶级支配和控制资本主义经济和政治的发展和运行，经济危机周期性爆发

    3. 资本主义的内在矛盾决定了资本主义必然被社会主义所代替，社会主义代替资本主义是一个复杂的长期的历史过程

      • 资本积累推动资本主义基本矛盾不断激化并最终否定资本主义自身
      • 国家垄断资本主义是资本社会化的更高形式，将成为社会主义的前奏
      • 资本主义社会存在着资产阶级和无产阶级两大阶级之间的矛盾和斗争
