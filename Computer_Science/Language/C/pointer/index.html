    指针¶

    Tips

    1. a为指针，a[i] ＝ *(a+i)
    2. *p++: ++和*的优先级相同，从右向左运算
    3. ⽆论指向什么类型，所有的指针的⼤⼩都⼀样，因为都是地址
    4. 但是指向不同类型数据的指针不能直接互相赋值的 ，为了避免⽤错指针

    指针数组和数组指针¶

    1. 指针数组：储存指针
    C
    1
2
    int *a[10];
int *(a[10]);   // 等价

    Tips

    a不是指针，而是一个数组名；

    数组名a在大多数表达式中会转换为指向其第一个元素的指针（在这里为int**类型）

    1. 数组指针：指向数组
    C
    1
2
    int (*a)[10];  // 指向一个含有10个int元素的数组
int (*a)[];    // 指向一个未知大小的数组

    Notice!

    1. 用变量定义数组长度时，不能同时初始化

    字符串与指针¶

    Notice!

    &运算符不能用于没有地址的变量。

    e.g. &(a+b) &(a++) &(++a)均不正确

    字符串定义¶

    1. 定义：字符串是以空字符（'\0'）结尾的 char 类型数组。

    字符与字符串

    • 双引号：字符串
    • 单引号：单个字符
    • e.g. 'x' 是一个字符；"x" 是一个字符串（实际上由两个字符'x'、 '\0' 组成）

    字符串函数¶

    单字符的输入和输出

    1. getchar(): 读取但不存储输入；包括'\n'
    2. putchar(char a): 返回写了几个字符，返回EOF(-1)表示写失败

    头文件

    C
    1
    #include <string.h>

    1. scanf("%s", str);

    在遇到第一个空白（空格、制表符、换行符）时不再读取输入

    1. gets(str)

    读取整行输入，直至换行符（不读入换行符）

    Error

    无法限制输入长度，容易导致缓冲区溢出，所以用 fgets() 代替

    1. fgets(str, sizeof(str), stdin)
    • 会读入并且存储换行符（如果空间足够）
    • 最后一个参数是要读入的文件（如果读入从键盘输入的数据，则以 stdin 作为参数）
    • 与 fputs() 配合使用
    • 如果读到文件结尾则返回 NULL
    1. gets_s(str, sizeof(str))

    会读取换行符但是丢弃它

    strlen()

    C
    1
    size_t strlen(const char *s);

    计算包括空格和标点符号在内的字符数

    Tips

    \0标志字符串的结束，但不是字符串的⼀部，计算字符串长度时不包含末尾的\0.

    sizeof与strlen

    (1) 区分 sizeof 运算符：char a[10] = "string."; sizeof(a)=10; strlen(a)=7;

    (2)sizeof 与 strlen() 返回值均对应 %zd

    strcat()

    C
    1
    char *strcat(char *str1, const char *str2);

    把两个字符数组中的字符串连接起来（把字符串2连接到字符串1的后面，结果放在字符数组1中）

    Tips

    一定保证字符串1有足够的空间！！！

    1. strcpy() （全部复制）
    C
    1
    char *strcpy(char *dest, const char *src);

    将字符串2全部复制到字符数组1中去

    1. strncpy() （选择复制）
    C
    1
    char *strncpy(char *dest, const char *src, size_t n);

    n：表示将字符串2中的n个单个字符复制到字符数组1中，最少为0个，最多不能超过字符串2的长度

    1. strcmp()
    C
    1
    int strcmp(const char *str1, const char *str2);

    比较规则：

    • 如果全部字符相同，则认为两个字符串相等，返回0；
    • 若出现不相同的字符，则以第一对不相同的字符比较结果为准（'a'<'z'；'A'<'Z'）；
      • 如果字符串1 > 字符串2，则函数值返回一个正数
      • 如果字符串1 < 字符串2，则函数值返回一个负数

    Note

    字符串比较时，不能用等号来比较大小，而是使用 strcmp() 函数

    1. strncmp()
    C
    1
    int strncmp(const char *str1, const char *str2, size_t n);

    n：选择字符串的前n个字符进行比较

    1. puts(str)
    • 遇到空字符时停止
    • 只能输出字符串，而且自动在显示的字符串末尾加上换行符
    • 如果与fgets()混合使用，则末尾会有两个换行符
    1. fputs(str, stdout)
    C
    1
    int fputs(const char *s, FILE *stream)
    • 最后一个参数是要写入的文件（如果显示在显示器上，使用stdout作为参数）
    • 末尾不添加换行符
    1. printf("%s", str)
    • 输出多个字符串更加方便

    1. strlwr(str)): 将字符串中的大写字母转换成小写字母

    2. strupr(str): 将字符串中的小写字母转换成大写字母

    处理换行符的方法

    (1) 替换换行符为字符串结束符

    C
    1
2
    while (words[i] != '\n') i++;
words[i] = '\0';

    (2) 丢弃输入缓冲区中的多余字符

    C
    1
    while (getchar() != '\n') continue;

    字符串的修改
    1. 当指针直接指向字符串常量时，字符串常量通常存储在只读数据段，不能通过指针去修改字符串常量的内容（否则会导致运行时错误，如段错误）

    e.g. char* s = "Hello, world!";

    s实际上是const char* s，不能对s所指的字符串做写⼊和修改（即不能之后写s[0]='H';）

    1. 对于指向动态分配内存的指针字符串，其存储的字符串在动态分配的堆空间中，可以根据实际情况进行修改（只要操作合法且在分配的内存范围内）
    2. 如果需要修改字符串，应该⽤数组：char s[] = "Hello, world!";
