    ISA¶

    基本介绍¶

    • Instruction=opcode+operands（操作码+操作数）

      • 操作数一般为0/1/2/3

    • 指令设计的基本原则

      1. Simplicity favors regularity
      2. Make the common case fast
      3. Smaller is faster
      4. Good design demands good compromises

    ISA Design¶

    1. 不同操作数下同一指令的表示

      • 没有操作数的指令类似于栈的操作
      • 操作数越少，指令序列越长

    2. 寻址模式

      • 立即数寻址
        • 直接包含需要处理的数据
        • e.g. ADD #5
      • 直接寻址
        • 操作数包含数据的地址
        • e.g. ADD 100
      • 不直接寻址
        • 操作数包含数据的地址的地址
        • 寻找范围更大
        • e.g. ADD [100]
      • 寄存器寻址
        • 直接寻址
          • 寄存器中直接存储数据
          • e.g. ADD R5
        • 不直接寻址
          • 寄存器中存储数据的地址
          • e.g. ADD [R5]
      • 其余寻址模式
        • Indexed 寻址

    寄存器¶

    1. 程序计数器（PC）

    2. 浮点状态寄存器（fsr）：用于浮点舍入模式以及异常报告

      fsr的功能详述
      1. 浮点舍入模式控制
      • 就近舍入（Round to Nearest）：将数值舍入到最接近的可表示值。若出现中间值，例如 2.5，就会舍入到偶数，也就是 2.0。
      • 向上舍入（Round Up）：把数值朝正无穷大的方向舍入，比如 2.1 会舍入为 3.0。
      • 向下舍入（Round Down）：将数值朝负无穷大的方向舍入，例如 -2.9 会舍入为 -3.0。
      • 向零舍入（Round toward Zero）：直接截断小数部分，只保留整数部分，像 2.9 会舍入为 2.0，-2.9 会舍入为 -2.0。
      1. 异常报告功能
      • 上溢（Overflow）：当运算结果超出了浮点数所能表示的范围，例如 1e400（假设为双精度浮点数），就会发生上溢。
      • 下溢（Underflow）：运算结果过小，无法用浮点数精确表示时，如下溢情况。
      • 除以零（Division by Zero）：当进行除法运算时，除数为零，比如 1.0 / 0.0，就会触发该异常。
      • 无效操作（Invalid Operation）：进行一些未定义的运算，例如对负数开平方，即 sqrt(-1)，会引发无效操作异常。
      • 不精确（Inexact）：运算结果无法精确表示，需要进行舍入时，就会出现不精确的情况，如 1.0 / 3.0。

    3. 整数寄存器（32/64 bit）

      • 32个（x0~x31）
      • x0只能存储0
    4. 浮点数寄存器（单/双精度）
      • 32个（f0~f31）
    寄存器 ABI 名称 用途描述 saver
    x0 zero 硬件 0
    x1 ra 返回地址（return address） caller
    x2 sp 栈指针（stack pointer） callee

    x12-17 a2-7 函数参数 caller
    x18-27 s2-11 需要保存的寄存器 callee
    x28-31 t3-6 临时变量 caller

    基础整数指令集RV32I¶

    • 分类
      • 按照功能分类
        • ALU 指令
          • e.g. add,sub,addi...
        • Load/Store 指令
          • e.g. ld,lw,lh,sw,sd...
        • Branch/Jump 指令
          • e.g. jal(跳转),jalr,beq(比较)...
      • 按照编码格式分类
        • R,I,S,B,U,J
        • opcode占右边的7位，表示指令是什么类型

    31 25 24 20 19 15 14 12 11 7 6 0
    funct7 rs2 rs1 funct3 rd opcode

    • rd = rs1 op rs2
    • e.g. add rd,rs1,rs2
    • 没有not运算符，通过xor实现

    31 20 19 15 14 12 11 7 6 0
    imm[11:0] rs1 funct3 rd opcode

    • imm：有符号数，进行符号扩展
    • ALU 运算指令
      • rd = rs1 op imm
      • e.g. addi rd,rs1,imm
    • Load 指令
      • rd表示目标寄存器
      • [rs1]+imm表示内存地址
      • e.g. lw rd,imm(rs1)
    • Jalr 指令
      • rd表示目标寄存器，存储返回地址pc+4（如果不需要存储返回地址，rd=x0）
      • [rs1]+imm表示跳转的内存地址
      • e.g. jalr rd,rs1,imm

    31 25 24 20 19 15 14 12 11 7 6 0
    imm[11:5] rs2 rs1 funct3 imm[4:0] opcode

    • rs1：存放内存地址的基址
    • rs2：存放数据
    • imm：地址的偏移量（有符号数，进行符号扩展）
    • e.g. sd rs2,imm(rs1)

    Notice!

    • RISC-V的数据存储模式为小端模式（little endian）：数据的高字节储存在高地址
    • PowerPC使用大端模式

    31 25 24 20 19 15 14 12 11 7 6 0
    imm[12,10:5] rs2 rs1 funct3 imm[4:1,11] opcode

    • imm：
      • 跳转地址相对于当前地址的偏移量
      • 有符号数，进行符号扩展
      • 第一位始终为0

    31 12 11 7 6 0
    imm[31:12] rd opcode

    • imm：无符号数，左移12位，低位补0
    • LUI 指令
      • rd = imm
      • e.g. lui rd,imm
    • AUIPC 指令
      • rd = pc + imm
      • e.g. auipc rd,imm

    31 12 11 7 6 0
    imm[20,10:1,11,19:12] rd opcode

    • imm：
      • 跳转地址相对于当前地址的偏移量
      • 有符号数，进行符号扩展
      • 第一位始终为0
    • pc+imm：跳转地址
    • e.g. jal rd,imm

    NOP

    • 表示空指令，没有操作
    • e.g. ADDI x0,x0,0;

    函数调用¶

    1. 核心步骤

    • 传参

      • 前8个参数 → a0-a7
      • 超出的压栈（sp向低地址增长）：通过调整栈指针（sp）来实现 e.g. addi sp,sp,-framesize
      GAS
      1
      sd a8, -8(sp)   # 第9个参数存栈

    • 跳转

      • jal ra, func：跳转并保存返回地址到 ra（x1）

    • 执行

      • 使用栈空间存储局部变量和临时数据

    • 返回调用点

      • 结果存 a0，恢复寄存器，释放栈帧，ret 返回

    2. 函数序言（Prologue）（函数开始部分，为函数执行做准备）

    GAS
    1
2
3
4
5
    func:
    addi sp, sp, -16   # 分配栈帧（假设需16字节）
    sd   ra, 8(sp)     # 保存返回地址
    sd   s0, 0(sp)     # 保存被调用者保存寄存器
    addi s0, sp, 16    # 设置帧指针（可选）

    作用：

    • 保护 ra 和关键寄存器
    • 建立栈帧（局部变量通过 sp 或 s0 访问）

    3. 函数尾声（Epilogue）（函数执行结束时运行，恢复函数调用前的环境并返回）

    GAS
    1
2
3
4
    ld   ra, 8(sp)     # 恢复返回地址
ld   s0, 0(sp)     # 恢复寄存器
addi sp, sp, 16    # 释放栈帧
ret                # 返回（等价于 jalr x0, 0(ra)）

    4. 关键规则

    • 调用者保存（Caller-Saved）：a0-a7, t0-t6（若需保留，调用前压栈）
    • 被调用者保存（Callee-Saved）：ra, s0-s11, sp（函数内若使用，必须保存）
    叶子函数与非叶子函数
    • 叶子函数：不调用其他任何函数的函数
      • 无需保存返回地址ra
    • 非叶子函数：调用其他函数的函数
      • 必须保存返回地址ra
