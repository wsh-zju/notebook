    ADS 知识清单¶

    1 数据结构¶

    1.1 树¶

    1. BST - 性质： - 操作：查找 & 插入（时间复杂度），删除

    2. AVL

    • 目标：

    • 求解：平均搜索时间

    • 相关定义：平衡因子
    • 条件 1-2
    • 高度大小：最小节点数的递推公式、通项公式
    • 操作：调整平衡（4种）
    • 3个Notices
    1. Splay
    • 目标： （并不意味着每一步是 ）
    • 解决方法
    • 调整方式（1+2种）
    • 操作：删除，插入
    1. Red-Black - 条件（4个） - 相关定义：内部节点、外部节点 - 性质（路径） - 黑高：定义、记号、树的黑高 - 定理：红黑树的高度 - 操作
      • 插入：调整（1+1+2种）、时间复杂度
      • 删除：只有一个孩子，有两个孩子、没有孩子
      • AVL和红黑树的旋转次数比较：插入、删除
    2. B+树 - 结构特征 - 查找时间复杂度、深度、插入时间复杂度 - 基本操作：插入、删除 - M的最优选择

    1.2 堆¶

    1. 左倾堆： - 目标 - 空路径长度：定义、递推公式 - 性质：最大/小堆（有序性质）、二叉树（结构特性）
      • 重要性质（NPL）
      • 定理（总节点数和右路径长度）
      • 合并（插入）：递归（时间复杂度）、迭代、原始堆的合并操作时间复杂度
      • 代码：结构、合并代码（递归版）
      • DeleteMin：时间复杂度、操作
    2. 斜堆 Skew Heaps - 目标： - 合并：步骤、优点（3个）、缺点 - 轻重节点 - 摊还分析：势能函数、摊还时间复杂度（？听不懂了9-30）

    1.3 二项队列¶

    • 目标： （左倾堆、斜堆和二叉堆的单次插入时间复杂度）
    • 结构： \(B_k\) 的节点数，深度 \(d\) 处的节点数
    • 性质：唯一性、时间复杂度
    • 操作：
    • FindMin：根节点的个数，时间复杂度 + 优化后的时间复杂度
    • Merge：时间复杂度、代码
    • Insert：时间复杂度(公式+最坏)、平均时间、摊还分析
    • DeleteMin：步骤、时间复杂度、代码
    • 二项树实现：左孩子-右兄弟结构、合并操作（时间复杂度）、代码
