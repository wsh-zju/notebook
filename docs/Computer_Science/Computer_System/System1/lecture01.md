## 进制之间的转换
1. R进制 $\to$ 10进制：展开即可
2. 10进制 $\to$ R进制

- 整数：除基取余，从下至上
- 小数：称基取整，从上至下

3. 2进制 $\to$ 8/16进制：每3/4个一组转换为8/16进制（反之同理）
4. 8进制 $\to$ 16进制：通过2进制进行转换

## 数据表示
### 数值数据
#### 定点数（Fixed-point）
   
1. n位机器码的表示范围

- 无符号数：$0 \leqslant x \leqslant 2^n-1$
- 有符号数：**取决于编码方法**

2. 编码方法

=== "原码"
    **sign-and-magnitude**

    - 正数->负数：只改变符号位
        - e.g. 3:0000 0011 ; -3:1000 0011
    - **8 bit表示的范围**：-127（1111 1111）～127（0111 1111）
    - 缺点：有两种表示0的方法
        - +0:0000 0000
        - -0:1000 0000

=== "反码"
    **1's complement**

    - 对于基$r$，$n$位数$N$的反码为$(r^n-1)-N$
    - 当$r=2$，负数即为对正数每一位取反；正数保持不变
        - **8 bit表示的范围**：-127（1000 0000）～127（0111 1111）
    - 缺点：有两种表示0的方法
        - +0:0000 0000
        - -0:1111 1111


=== "补码"
    **2's complement**

    - 对于基$r$，$n$位数$N$的反码为$r^n-N$
    - 当$r=2$，负数即为对正数取反加一；正数保持不变
        - **8 bit表示的范围**：-128（1000 0000）～127（0111 1111）

=== "移码"
    **Frameshift code**
    
    - 定义：在真值的基础上加上一个固定的偏移量（Bias），使得指数部分可以用无符号整数表示
    - 应用：用于表示浮点数的指数部分

3. 符号扩展

- 扩展（expanding）
    - 有符号：符号扩展
    - 无符号：补0
- 截断（truncating）
    - 直接去掉高位
    - 只有较小的数不会改变初始值
