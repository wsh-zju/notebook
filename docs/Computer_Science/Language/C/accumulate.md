## 常见函数
### 绝对值函数
1. `<stdlib.h>`

- `abs()` : int
- `labs()` : long int
- `llabs()` : long long int

2. `<math.h>`

- `fabs()` : double

### 字符串和整数之间的转换
1. `strtol(str,&a,10);`: 字符串转换为整数（第三个参数表示十进制）
2. `sprintf(str,"%d",num);`: 整数转换为字符串

```c
char str2[]= "0x12";
long int num2= strtol(str2, NULL, 0);      //base=0代表自动判断进制
printf("转换后的值: %ld\n", num2);
sprintf(str2, "%lo", num2);
printf("转换后的字符串: %s\n", str2);
```

### `<math.h>`
1. `pow()`: 返回`base`的`exponent`次幂的值

```c
double pow(double base, double exponent);
```

2. `exp()`: 返回`e`的`x`次幂的值

```c
double exp(double x)
```

3. `sqrt()`: 开方

```c
double sqrt(double b);
```

### 动态分配内存 `<stdlib.h>`
1. `malloc`

```c
void* malloc(size_t size);   //函数原型
int *ptr; 
ptr = (int *)malloc(5 * sizeof(int));
```

- 用于在内存的堆区分配**指定字节大小**的连续内存空间
- `size`: 要分配的字节数
- **返回值**: 
    - 如果分配成功，则返回指向所分配内存空间起始地址的指针
    - 如果分配失败（例如系统内存不足等原因），则返回`NULL`

1. `realloc`

```c
void* realloc(void* ptr, size_t size);
int *ptr = (int *)realloc(ptr, 10 * sizeof(int));
```

- 用于对已经分配的内存空间**调整大小**
- `ptr`: 之前分配内存的起始指针
- `size`: 调整后想要的内存大小（字节数）
- **返回值**: 
    - 如果调整成功，会返回当前指向内存空间起始地址的指针
    - 如果无法按照要求调整大小，则返回`NULL`，原内存空间不会被修改

3. `calloc`

```c
void* calloc(size_t num, size_t size);
int *arr; 
arr = (int *)calloc(3, sizeof(int));
```

- 用于在堆区分配指定数量（`num`个）且指定大小（`size`个字节）的连续内存空间，并将分配的内存空间初始化为全`0`
- **返回值**: 
    - 如果分配成功，则返回指向所分配内存起始地址的指针
    - 如果分配失败，则返回`NULL`

4. `free`

```c
void free(void* ptr);
free(arr);
```

用于释放之前通过 `malloc`、`calloc` 或 `realloc` 等函数分配的内存空间

### 陌生运算符
1.  **`!` 运算符**：逻辑非运算符，用于将表达式的真值取反
2. **`,` 运算符**

- 将多个表达式连接在一起，**从左到右**依次计算这些表达式的值
- 整个逗号表达式的值是**最后一个表达式的值**

3. **三目运算符**（唯一）

- 条件运算符：`表达式1 ? 表达式2 : 表达式3`
- **计算方法**：先执行表达式1，如果表达式1为真，则执行表达式2，否则执行表达式3

### 宏中使用的运算符
1. `#`运算符用于在宏定义中把宏参数转换为字符串常量
2. `##`运算符

- **功能**：在宏定义中用于连接两个标识符（变量名、函数名、类型名等），形成一个新的标识符
- **应用**：在创建具有不同命名的相关变量、函数等方面非常有用

## `gcc`终端命令
1. `gcc file.c`：将C语言文件编译为可执行文件。如果源文件中包含多个函数，则会自动链接必要的库文件
2. `gcc -o output file.c`：指定编译输出文件的名称
3. `gcc -c file.c`：将C语言文件编译为目标文件，而不链接任何库文件
4. `gcc -E file.c`：预处理C语言文件，并将结果输出到标准输出
5. `gcc -Wall file.c`：开启所有警告信息
6. `gcc -g file.c`：生成可以调试的可执行文件
7. `gcc -O level file.c`：开启优化选项，其中 `level` 的值可以是 `0、1、2、3、s`
8. `gcc -I path file.c`：添加一个包含文件搜索路径
9. `gcc -L path file.c -l library`：添加一个库文件搜索路径
10. `gcc -D macro=value file.c`：在编译时定义一个宏
编译预处理程序（cpp）终端指令，：
11. `gcc -save-temps a.c`：保留编译链接过程中的中间过程文件（`.i` 预处理文件、`.s` 汇编文件、`.o` 目标文件）
12. `gcc a.c b.c`：多个`.c`文件编译（一个`.c`文件是一个编译单元，编译器每次编译只处理一个编译单元）

!!! tip "Tips"
    可以通过输入 `man gcc` 来查看完整的帮助文档，或者通过输入 `gcc --help` 来查看常用选项的简介

    3. **大小写字母的转换**
    
    - 字母在ASCII码表中按顺序排列，大写字母和小写字母是分开的
    - `'a'-'A'` 得出大写字母和小写字母之间的间距，
        - `a + 'a'-'A'` 将 `a` 从大写转换为小写
        - `a + 'A'-'a'` 将 `a` 从小写转换为大写
