## 转义字符
1. `Escape char`：⽤来表达⽆法打印出来的控制字符或特殊字符
2. **组成**：由⼀个反斜杠`\`开头，后⾯跟上另⼀个字符，这两个字符合起来，组成了⼀个字符

| 转义字符 | 含义 |
|:--:|:--:|
| `\b` | 退格 |
| `\t` | 水平制表符 |
| `\"` | 双引号 |
| `\'` | 单引号 |
| `\n` | 换行符 |
| `\r` | 回车 |
| `\\` | 反斜杠本身 |


## `gcc`终端命令
1. `gcc file.c`：将C语言文件编译为可执行文件。如果源文件中包含多个函数，则会自动链接必要的库文件
2. `gcc -o output file.c`：指定编译输出文件的名称
3. `gcc -c file.c`：将C语言文件编译为目标文件，而不链接任何库文件
4. `gcc -E file.c`：预处理C语言文件，并将结果输出到标准输出
5. `gcc -Wall file.c`：开启所有警告信息
6. `gcc -g file.c`：生成可以调试的可执行文件
7. `gcc -O level file.c`：开启优化选项，其中 `level` 的值可以是 `0、1、2、3、s`
8. `gcc -I path file.c`：添加一个包含文件搜索路径
9. `gcc -L path file.c -l library`：添加一个库文件搜索路径
10. `gcc -D macro=value file.c`：在编译时定义一个宏
编译预处理程序（cpp）终端指令，：
11. `gcc -save-temps a.c`：保留编译链接过程中的中间过程文件（`.i` 预处理文件、`.s` 汇编文件、`.o` 目标文件）
12. `gcc a.c b.c`：多个`.c`文件编译（一个`.c`文件是一个编译单元，编译器每次编译只处理一个编译单元）

!!! tip "Tips"
    可以通过输入 `man gcc` 来查看完整的帮助文档，或者通过输入 `gcc --help` 来查看常用选项的简介
