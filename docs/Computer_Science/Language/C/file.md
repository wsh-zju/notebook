## 格式化输入输出
### 输出 printf
1. **返回值**：输出的字符数
2. **格式**：`%[flags][width][.prec][hlL]type`

|`flag`|含义|示例代码|输出|
|:--:|:--:|:--:|:--:|
|`-`|左对齐| `printf("%-6d", 123);`| `123   `|
|`+`|在正数前面加`+`或`-`| `printf("%+d", 123);`| `+123` |
|`(space)`|正数留空 （前面加空格）| `printf("% d", 123);`| ` 123` |
|`0`|`0`填充| `printf("%06d", 123);` |`000123`|

|`width`/`.prec`|含义|示例代码|输出|
|:--:|:--:|:--:|:--:|
|`number`|最⼩字符数 （包括小数点所有）|`printf("%8.2f", 3.14159);`| `   3.14`|
|`*`|第一个参数表示总字符数| `printf("%*d", 5, 123);` | `  123`|
|`.number`|⼩数点后的位数|`printf("%.3f", 3.14159);` | `3.142`|
|`.*`|第一个参数表示⼩数点后的位数|`printf("%.*f", 2, 3.14159);` | `3.14` |

|类型修饰`hlL`|含义|
|:--:|:--:|
| `hh`    | 单个字节    |
| `h`    | short    |
| `l`    | long    |
| `ll`    | long long    |
| `L`    | long double    |

| `type`   | 数据类型    | `type`   | 数据类型    |
|:--:|:--:|:--:|:--:|
| `i`/`d` | `int`    | `g`   | `float`    |
| `u`    | `unsigned int` | `G`    | `float`    |
| `o`    | 八进制    | `a`/`A` | 十六进制浮点 |
| `x`    | 十六进制    | `c`    | `char`    |
| `X`    | 字母大写的十六进制 | `s`    | 字符串    |
| `f`/`F` | `float`    | `p`    | 指针    |
| `e`/`E` | 指数    | `n`    | 读入/写出的个数 |

### 输入 scanf
1. **返回值**：输入的字符数
2. **格式**：`%[flag]type`

| `flag` | 含义         | `flag` | 含义          |
|:------:|:-------:|:------:|:--------:|
| `*`    | 跳过         | `l`    | `long`/`double`  |
| 数字 | 最大字符数   | `ll`   | `long long`     |
| `hh`   | `char`        | `L`    | `long double`   |
| `h`    |`short`       |      |               |

 
| `type` | 数据类型   | `type`     |数据类型   |
|:--:|:------:|:------:|:------:|
| `d`    | `int`               | `s`        | 字符串(单词)       |
| `i`   | 整数(可能十六/八进制) | `[...]`    | 所允许的字符       |
| `u`    | `unsigned int`      | `p`        | 指针               |
| `o`    | 八进制            | `x`        | 十六进制           |
| `c`    | `char`   | |        |

??? note "[...]详解"
    | 格式      | 说明          |
    |:--------:|:-----------:|
    | `%[a-z]`        | 只接受小写字母             |
    | `%[^abc]`       | 接受除了`a`、`b`、`c`之外的所有字符（`^`表示排除）|
    | `%[0-9.]`       | 只接受数字和小数点（可用于读取浮点数）    |

## 文件操作函数
**打开文件的标准代码**

```c
FILE* fp= fopen("file","r");
if( fp ) {
    fscanf(fp,...);
    fclose(fp);
} else{
    ...
}
```

=== "文件打开函数"
    `fopen()`

    ```c
    FILE *fp;
    fp = fopen("test.txt", "r"); 
    // 以只读模式打开名为test.txt的文件；如果文件不存在，对于只读模式会返回NULL
    ```

    1. **功能**：打开一个文件，并返回一个指向该文件的**文件指针**（后续进行文件操作的关键）
    
    2. **打开文件的模式**

    | mode | 功能    |
    |---|---|
    | `r`   | 打开只读    |
    | `r+` | 打开读写，从文件头开始    |
    | `w`   | 打开只写。如果不存在则新建，如果存在则清空    |
    | `w+` | 打开读写。如果不存在则新建，如果存在则清空    |
    | `a`   | 打开追加。如果不存在则新建，如果存在则从文件尾开始    |
    | `a+` | 打开追加并读写    |
    | `x`   | 只新建，如果文件已存在则不能打开    |

    !!! tip "Tips"
        后边加上`b`为对二进制文件的操作

=== "文件关闭函数"
    `fclose()`
    
    ```c
    fclose(fp);
    // 关闭之前打开的文件指针fp所指向的文件
    ```

    **功能**：关闭一个已经打开的文件（不关闭文件可能会导致数据丢失、文件损坏或者占用过多的系统资源）

=== "文件定位函数"
    1. `fseek()`：用于**设置文件位置指针的位置**；可以将指针向前或向后移动指定的字节数，从而实现对文件的随机访问

    - `SEEK_SET`: 从头开始
    - `SEEK_CUR`: 从当前位置开始
    - `SEEK_END`: 从尾开始(倒过来)

    ```c
    fseek(fp, 10L, SEEK_SET);
    // 将文件fp的位置指针从文件开头（SEEK_SET）向后移动10个字节
    ```
    
    2. `ftell()`：返回**文件位置指针的当前位置**，通常**返回相对于文件开头的字节数**

    ```c
    long pos = ftell(fp);
    // 获取文件fp的位置指针当前位置
    ```

    3. `rewind()`：将文件位置指针**重新定位到文件的开头**

    ```c
    rewind(fp);
    // 将文件fp的位置指针重新定位到文件开头
    ```

=== "文件结束判断函数"
    `feof()`

    ```c
    while (!feof(fp)){
        // 读取文件内容
    }
    ```

    1. **功能**：用于判断文件是否读取到了末尾
    2. **输出**：当文件位置指针到达文件末尾时，`feof()`函数返回真（1），否则返回假（0）
    
    
=== "字符读取函数"
    `fgetc()`
    
    ```c
    char ch;
    ch = fgetc(fp);
    // 从文件fp中读取一个字符并存储到ch中
    ```
    
    **功能**：
    
    - 从指定的文件中读取一个字符，使文件位置指针向后移动一个字符的位置
    - 如果读取到文件末尾，会返回`EOF`
    
=== "字符串读取函数"
    `fgets()`/`gets()`

    ```c
    char str[100];
    fgets(str, sizeof(str), fp);
    // 从文件fp中读取一行字符串存放到str数组中
    ```
    
    **功能**：从指定文件中读取一行字符串，直到遇到换行符'\n'或者读取了`指定长度-1`个字符（最后一个字符要用来存储'\0'）（比较安全，可以有效防止缓冲区溢出。）
    

=== "格式化读取函数"
    `fscanf()`

    ```c
    int num;
    fscanf(fp, "%d", &num);
    // 从文件fp中按照整数格式读取一个数据存储到num变量中
    ```
    
    **功能**：按照指定的格式从文件中读取数据
 
    
=== "字符写入函数"
    `fputc()`/`putc()`

    ```c
    char ch = 'A';
    fputc(ch, fp);
    // 将字符'A'写入文件fp中
    ```

    **功能**：
    
    - 将一个字符写入指定的文件中，同时文件位置指针会向后移动一个字符的位置
    - 当写入操作成功时，它会返回**写入的字符**；如果写文件失败，`fputc()`函数返回`EOF`（-1）    

=== "字符串写入函数"
    `fputs()`

    ```c
    char str[]="Hello, World!";
    fputs(str, fp);
    // 将字符串"Hello, World!"写入文件fp中
    ```
    
    **功能**：将一个字符串写入指定的文件中，不包括字符串结尾的'\0'

    
=== "格式化写入函数"
    `fprintf()`

    ```c
    int num = 10;
    fprintf(fp, "%d", num);
    // 将整数10按照整数格式写入文件fp中
    ```

    **功能**：按照指定的格式将数据写入文件
