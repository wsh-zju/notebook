# <i class="fa-brands fa-linux"></i> 嵌入式系统

1. **定义**：嵌入式系统是以应用为中心，以计算机技术为基础，采用可剪裁软硬件，适用于对功能、可靠性、成本、体积、功耗等有严格要求的专用计算机系统
2. **结构**：嵌入式系统一般由嵌入式微处理器、外围硬件设备、嵌入式操作系统（可选），以及用户的应用软件系统等四个部分组成
    1. 软件部分包含操作系统和应用软件，<mark>但是应用软件必须有，操作系统可以没有</mark>
    2. 硬件部分有嵌入式处理器和嵌入式外围设备
3. **嵌入式系统与桌面通用系统的区别**

## 嵌入式系统硬件

1. **嵌入式处理器分类**：
    1. 嵌入式微控制器 MCU：以 CPU 为基础，将微处理器装配在专门设计的电路板上，只保留和嵌入式应用有关的功能 **e.g.** 电子温度计（无处理器）
    2. 嵌入式 DSP 处理器：**专门用于数字信号处理**的嵌入式处理器，主要任务是对连续变化的信号进行快速计算
    3. 嵌入式微处理器 MPU：又称**单片机**，将整个计算机系统浓缩集成到一块芯片中
    4. 嵌入式片上系统 SoC
