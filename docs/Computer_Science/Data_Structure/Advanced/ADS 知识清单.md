1. **BST**

2. **AVL**

   - **目标**：

   - **求解**：平均搜索时间
   - **相关定义**：平衡因子
   - **条件** 1-2
   - **高度大小**：==最小节点数的递推公式==、通项公式
   - **操作**：调整平衡（4种）

3. **Splay**

   - **目标**：																（并不意味着每一步是          ）
   - **解决方法**
   - **调整方式**（1+2种）
   - **操作**：==删除==，插入

4. **Red-Black**
   - **条件**（4个）
   - **相关定义**：内部节点、外部节点
   - **性质**（路径）
   - **黑高**：**定义**、记号、树的黑高
   - **定理**：红黑树的高度
   - **操作**
     - **插入**：调整（1+1+2种）、时间复杂度
     - ==**删除**==：只有一个孩子，有两个孩子、**没有孩子**
   - AVL和红黑树的**旋转次数比较**：插入、删除
5. **B+树**
   - **结构特征**
   - 查找时间复杂度、深度
   - **基本操作**：插入、删除
   - M的最优选择
