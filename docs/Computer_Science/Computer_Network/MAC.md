# MAC 子层

## 多路访问协议

### 1. 三大类多路访问协议

| 类型     | 特点                         | 代表协议                     |
| -------- | ---------------------------- | ---------------------------- |
| 随机访问 | 允许竞争，冲突不可避免       | ALOHA、CSMA、CSMA/CD         |
| 受控访问 | 通过协调或预约减少冲突       | 位图协议、令牌、二进制倒计数 |
| 有限竞争 | 结合随机竞争与受控访问的优点 | 自适应树搜索                 |

### ALOHA 协议

#### 纯 ALOHA：想发就发

可能**随时**发生冲突。冲突的帧完全被破坏，破坏了的帧要**重传**。

> 帧时：发送一个标准长的帧所需的时间
>
> 一个帧时间内产生k个帧的概率服从**泊松分布**
>
> 不生成帧的概率：\(P[0] = e^{-G}\)

$$
S=GP_0=Ge^{-2G}
$$

**G=1/2时，纯ALOHA信道的利用率最高为18.4%**

- **\(G\) 网络负载**：时间T内所有通信站总共发送的帧平均值（新产生的+重传的）

- **\(S\) 吞吐量**：在发送时间 T 内发送<u>成功</u>的平均帧数 

  - 0<S<1
  - 一般用S接近于1的程度来衡量信道的利用率

- **\(P_0\)：**一帧发送成功(即未发生冲突)的概率（与p[0]不同）
  $$
  P_0= P[0]P[0] = (e^{-G})^2= e^{-2G}
  $$

#### 分隙 ALOHA

将时间划分为时隙，只能在时隙起点发送。

**冲突只发生在时隙起点**。
\[
 S=Ge^{-G} 
\]


**G=1时，最大吞吐量为  $S_{\max}=\frac{1}{e}\approx0.368$**，约为纯 ALOHA 的两倍。

### CSMA：载波侦听多路访问

核心思想：先听后发。

| 类型            | 工作方式                         |
| --------------- | -------------------------------- |
| 非持续式 CSMA   | 信道忙时**等待随机时间**，再侦听 |
| 1-持续式 CSMA   | 信道一空闲就立即发送             |
| (p)-持续式 CSMA | 信道空闲时以概率 (p) 发送        |

先侦听并不能彻底避免冲突，因为信号传播存在延迟。

### CSMA/CD（1-持续）

主要用于传统共享式、半双工以太网。

工作流程：

1. 侦听信道，信道空闲时发送。
2. 发送过程中继续监听，检测冲突。
3. 发生冲突后发送**强化信号（Jam）**（告诉所有节点发生冲突，不要继续发送）
4. 如果发生冲突，等待一个随机分布的时间再侦听

关键考点：

- **帧必须足够长，至少一个冲突窗口的时间**，才能保证发送方在发送完成前检测到冲突。
- 现代全双工交换式以太网通常不使用 CSMA/CD。

> **冲突窗口**：即发送站发出帧后能检测到冲突（碰撞）的最长时间。
>
> 数值上：等于最远两站传播时间的两倍，即2D（D是单边延迟）

？**采用二进制指数退避算法**

### 5. 受控访问与有限竞争

- 位图协议： 每个站点通过自己的时隙声明是否需要发送，再按顺序传输。
- 令牌传递： 获得令牌的站点才能发送。
- 二进制倒计数： 通过站点编号竞争，高编号优先。
- 自适应树搜索： 将竞争站点逐步划分为更小的组，直到确定可以成功发送的站点。

#### 自适应树搜索协议

将竞争站点逐步划分为更小的组，直到确定可以成功发送的站点。

多个站点冲突不发送，下一时隙再细分

### 以太网

**二进制指数后退的CSMA/CD**

• 确定基本退避时间槽，其长度为以太介质上往返传播时间(2𝜏) *，*以太网中设为**512比特时间**

• 发生 \(k\) 次碰撞后，主机从以下集合中随机选择退避时隙数 r：\[ \{0,1,\ldots,2^k-1\} \]

• **重传所需的时延就是 *r* 倍的时间槽2𝜏；**

• 当重传达 16 次仍不能成功时即丢弃该帧，并向高层报告

## WIFI

#### CSMA/CA 协议

带碰撞避免的载波侦听多路访问

>  IFS（帧间间隔）：在无线帧之间按规则保留的时间
>
> - SIFS是短帧间间隔；DIFS是DCF帧间间隔
> - SIFS短于DIFS，使ACK等**及时响应**先于普通新竞争

1. 侦听信道，判断是否空闲。
2. 信道空闲后等待 **DIFS**（DCF 帧间间隔）。
3. **随机选择退避计数**，在符合条件的空闲时隙中递减。
4. 计数归零后发送数据。
5. 接收方返回 ACK，确认本次无线链路接收成功。
6. 如果没有收到 ACK，发送方认为本次传输可能失败，并进行重传。

#### RTS/CTS：预约信道，解决隐藏站点问题

- RTS（请求发送）由发送者发出；CTS（允许发送）由接收者回应
- 取得机会后可按RTS → CTS → DATA → ACK交换，以**SIFS**衔接



> ##### 网桥自学习与转发题：核心知识点
>
> 1. 自学习（Learning）：根据帧的源 MAC 地址，记录其对应的入端口。
> 2. 目的地址未知（Flooding）：转发到除入端口外的所有端口。
> 3. 目的地址已知（Forwarding）：只转发到目的地址对应的端口。
> 4. 入端口与目的端口相同（Filtering）：不转发。
> 5. 连续传输：每次传输后更新转发表，下一题沿用更新后的表。
