
# <i class="fa-solid fa-landmark"></i> 毛泽东思想和中国特色社会主义理论体系概论

## 毛泽东思想及其历史地位

1. 历史条件
   1. 时代背景：世界进入帝国主义和无产阶级革命时代
   2. 实践基础：中国共产党领导人民进行革命和建设的成功实践
2. **毛泽东思想形成和发展的基础**是革命和建设正反两方面的历史经验
3. ==农村包围城市、武装夺取政权的思想，标志着**毛泽东思想的初步形成**——中国革命的新道路==（土地革命战争时期）
4. ==新民主主义革命理论的系统阐述，实现了马克思主义与中国革命实践相结合的历史性飞跃，标志着**毛泽东思想趋于成熟**==（抗日战争时期）
5. **1945年，中共七大**将毛泽东思想写入党章
6. 统一战线、武装斗争和党的建设是中国共产党**在中国革命中战胜敌人的三大法宝**
7. ==**毛泽东思想活的灵魂**：实事求是（精髓）、群众路线、独立自主==
   1. 实事求是：**马克思主义的根本观点**
   2. 群众路线：**党的生命线和根本工作路线**，是我们党永葆青春活力和战斗力的重要传家宝
      1. 全心全意为人民服务，是我们党一切行动的根本出发点和落脚点 ，是**我们党区别于其他一切政党的根本标志**
8. 马克思主义中国化的第一个重大理论成果：毛泽东思想

## 新民主主义革命理论

1. 近代中国国情和中国革命的时代特征
   1. **主要矛盾**：帝国主义和中华民族的矛盾（最主要）、封建主义和人民大众的矛盾
   2. **根本任务**：推翻“三座大山”（帝国主义、封建主义、官僚资本主义的统治）
   3. 革命性质：资产阶级民主革命
   4. 中国革命要分两步走：（民主主义革命是社会主义革命的必要准备，社会主义革命是民主主义革命的必然趋势）
      1. 完成反帝反封建的新民主主义革命任务
      2. 完成社会主义革命任务
2. ==**新民主主义革命总路线**：无产阶级领导的，人民大众的，反对帝国主义、封建主义和官僚资本主义的革命==（1948年毛泽东完整表述）
   1. 对象：三座大山（首要对象：帝国主义）
   2. **最基本的动力**：无产阶级——近代中国最进步的阶级，是中国革命的领导力量
   3. **中国革命的主力军**：农民（==农民问题是中国革命的**基本问题**==）
   4. ==**领导力量**：无产阶级及其政党==的领导是中国革命取得胜利的**根本保证**（无产阶级的领导权是中国革命的**中心问题**，也是新民主主义革命理论的核心问题）
   5. **性质**：资产阶级民主主义革命
   6. **革命前途**：社会主义
3. **新民主主义革命的基本纲领**
4. **道路**：农村包围城市、武装夺取政权（根本在于处理好土地革命、武装斗争、农村革命根据地建设之间的关系）
   1. **土地革命**是民主革命的基本内容
   2. **武装斗争**是中国革命的主要形式，是农村根据地建设和土地革命的强有力保证
   3. **农村革命根据地**是中国革命的战略阵地，是进行武装斗争开展土地革命的依托
5. **新民主主义革命的三大法宝**：统一战线、武装斗争、党的建设
   1. 工农联盟是统一战线的基础
   2. 武装斗争：
      1. 坚持党对军队的绝对领导，是建设新型人民军队的根本原则
      2. 全心全意为人民服务是人民军队的唯一宗旨

   3. 党的建设
      1. 党内思想的主要矛盾：党内无产阶级思想和非无产阶级思想之间的矛盾
      2. **三大优良作风**：理论联系实际、密切联系群众、批评与自我批评相结合（==中国共产党区别于其他任何政党的显著标志==）


## 社会主义改造理论

1. ==**过渡时期的总路线**：“一化三改”==
   1. 社会主义工业化
   2. 对个体农业、手工业、资本主义工商业的社会主义改造
2. **社会主义改造道路**
   1. 农业改造道路：互助合作
   2. 农业改造原则：自愿互利，典型示范和国家帮助
   3. 农业/手工业改造方针：积极领导、稳步前进
   4. 资本主义工商业
      1. 改造方法：和平赎买
      2. 步骤
         1. 初级形式的国家资本主义
         2. 个别企业的公私合营
         3. 全行业的公私合营
      3. ==利润分配：第一二步都采用四马分肥；第三部定股定息==
3. **社会主义改造的历史经验**
4. 社会主义制度确立：1956年

## 社会主义建设道路初步探索

1. ==**1956.5/6 《论十大关系》：标志着党探索社会主义建设道路的良好开端**==
   1. **一个基本方针**：调动一切积极因素为社会主义建设服务
   2. 第一大关系也是最重要的关系：重工业、轻工业和农业的关系
2. **社会主义社会的基本矛盾**：仍然是⽣产关系和⽣产⼒之间的⽭盾，上层建筑和经济基础之间的⽭盾（非对抗性、既相适宜又相矛盾）
   1. 敌我矛盾解决方法：专政
   2. **人民内部矛盾解决方法**：民主（总方针）
      1. 思想政治：团结——批评——团结
      2. 物质利益、分配：统筹兼顾、适当安排
      3. 人民群众和政府机关：民主集中制
      4. 科学文化：百花齐放、百家争鸣
      5. 民主党和共产党：长期共存、互相监督
      6. 民族之间：民族平等、团结互助
3. 1956.9 中共八大主要矛盾：人民对于建立先进的工业国的要求同落后的农业国的现实之间的矛盾

## “三个代表”重要思想

1. **基本问题**：建设什么样的党，怎样建设党
2. 贯彻“三个代表”要求：
   1. **关键**：坚持与时俱进
   2. **核心**：保持党的先进性
   3. **本质**：坚持执政为民
3. **核心观点**：
   1. 始终代表中国先进生产力的发展要求
   2. 始终代表中国先进文化的前进方向
   3. 始终代表中国最广大人民的根本利益
4. **主要内容**：
   1. **发展是党执政兴国的第一要务**
   2. 建设社会主义政治文明，最根本的就是要坚持党的领导、人民当家做主和依法治国的有机统一
   3. 坚持党的领导，核心是坚持党的先进性，重点是加强党的执政能力建设
5. **始终做到“三个代表”，是我们党的立党之本，执政之基，力量之源**
