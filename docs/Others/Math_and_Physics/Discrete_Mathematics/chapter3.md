## 函数的增长
1. $f(x) = O(g(x))$:$|f(x)| \leq C|g(x)|$

2. $f(x) = \Omega(g(x))$:$|f(x)| \geq C|g(x)|$

3. $f(x) = \Theta(g(x))$:$f(x) = O(g(x))$ 且 $f(x) = \Omega(g(x))$
