# 卡片与分栏简写

标记单独占一行，顶格书写。每个块用一行 `:::` 结束；正文仍使用普通 Markdown。

## 一张卡片

```markdown
::: card

## 网络基础

这里写正文，支持 **加粗**、列表、表格、公式和代码块。

:::
```

同一页面连续写多张卡片即可。卡片容器、翻页按钮、进度条和浏览面板会自动生成，浏览标题取自卡片内的 `##` 标题。

七类卡片使用莫兰迪配色，颜色应用于编号、淡彩背景和悬停光晕：

| 写法 | 类型 | 配色 |
| --- | --- | --- |
| `::: card` | 普通 | 雾蓝 |
| `::: card concept` | 概念 | 鼠尾草绿 |
| `::: card exam` | 考点 | 燕麦金 |
| `::: card mistake` | 易错 | 豆沙红 |
| `::: card example` | 例题 | 陶土橘 |
| `::: card summary` | 总结 | 灰紫 |
| `::: card question` | 思考 | 灰青 |

## 二栏与三栏

用 `|||` 换到下一栏。二栏用一次分隔，三栏用两次分隔。

```markdown
::: card concept

## 路由与转发

::: columns 2

### 路由

决定分组经过的路径。

|||

### 转发

在当前设备选择输出接口。

:::

:::
```

最后两行 `:::` 分别关闭分栏和卡片。三栏写法如下，也可直接在普通笔记里使用：

```markdown
::: columns 3

第一栏

|||

第二栏

|||

第三栏

:::
```

每栏支持列表、图片、公式、代码块以及 `!!!` 提示框。小屏幕自动按第一、第二、第三栏的顺序纵向排列。

在分栏开头加括号可指定各栏宽度比例，不写则等宽：

```markdown
::: columns 2 (2:1)

左栏占可分配宽度的 2/3。

|||

右栏占可分配宽度的 1/3。

:::
```

三栏可写 `::: columns 3 (1:2:1)`。比例按从左到右排列，支持正整数、小数以及逗号分隔（如 `(1.5, 1)`）；数字个数必须与栏数一致。小屏幕仍纵向排列，导出 PDF 时保留指定比例。

同页请连续放置卡片，使用一组卡片即可；不要再手写 `.card-deck` 和翻页控件。卡片和分栏分别不支持同类嵌套。代码围栏中的这些标记会原样展示，不会被展开。

实际示例：[计算机网络 · 引言](../../Computer_Science/Computer_Network/introduction.md)。

## 卡片内的重点块

```markdown
::: note

**重点：**协议是“水平的”，服务是“垂直的”。

:::
```

可以放在卡片或分栏里，也支持列表和其他 Markdown 内容。提示框内部也可以放分栏；分栏和提示框各自不支持同类嵌套，即使中间隔着其他块也不可以。普通的 `!!! note` 提示框仍可照常使用。

也可指定类型和可选的纯文本标题，正文不需要缩进：

```markdown
::: note warning 注意事项

**带宽**与实际传输速率不是同一个概念。

- 这里可以写列表
- 也可以放公式、图片和代码块

:::
```

| 类型 | 配色 |
| --- | --- |
| `info` | 雾蓝 |
| `tip` | 鼠尾草绿 |
| `warning` | 陶土橘 |
| `danger` | 豆沙红 |
| `example` | 灰紫 |
| `question` | 灰青 |
| `summary` | 燕麦金 |

例如 `::: note tip 小技巧`、`::: note danger 易错点`。省略标题（`::: note tip`）只显示正文；省略类型（`::: note`）则跟随当前卡片的颜色。也可以直接跟标题，如 `::: note 注意事项` 或 `::: note Example`，使用当前卡片颜色。只有上表的小写类型名会被识别为类型，因此 `::: note example` 是无标题的紫色框，`::: note Example` 是标题为 Example 的默认框。提示框不可相互嵌套。

## 卡片中的彩色文字

沿用颜色类名即可，卡片内会自动使用配套的莫兰迪文字色，并适配深色模式：

```html
<span class="green">屏蔽掉不同传输媒体和通信手段的差异</span>
```

`blue` 对应普通，`green` 对应概念，`yellow` 对应考点，`red` 对应易错，`orange` 对应例题，`purple` 对应总结，`cyan` 对应思考。

如果希望文字自动跟随所在卡片的类型颜色，使用 `accent`：

```html
<span class="accent">这段文字跟随当前卡片配色</span>
```

## 图片宽度简写

在图片后紧跟 `(69)`，即可设置宽度为所在容器的 69%，默认居中，上下留白 20px：

```markdown
![alt text](image/1-2.png)(69)
```

也支持中文括号 `（69）`、小数和百分号，如 `(60.5%)`。宽度范围为大于 0、至多 100。分栏内的百分比相对于该栏；不加括号的图片保持原有样式，原来的 `{style="..."}` 写法仍可使用。

## 导出 PDF

点击翻页控件旁的 **导出 PDF**，在浏览器打印窗口选择 **另存为 PDF**。

- 导出有内容的卡片（跳过空白草稿），每张卡片另起一页，使用与网页卡片相同的 16:9 自定义纸张。
- 保留当前主题、颜色、标题编号和二／三栏布局，隐藏导航与操作按钮。字号与内边距按导出前网页卡片的实际尺寸保持；移除卡片圆角与阴影，避免跨页割裂。
- 建议启用打印窗口的“背景图形”，关闭“页眉和页脚”，缩放保持 100%。
- 内容过长时允许延续到下一页，避免截断；需要一页一张时，请拆分过长的卡片。
- 折叠答案保持当前展开状态，想导出答案时请先展开。
